# 中原诗词文旅小程序：研学路线 + 50首诗词版

本版本在原 Beta 原型基础上加入：
1. 《河南诗词50首.xlsx》中的50首诗词；
2. 《研学路线高清版.pdf》整理出的“跟着《诗经》游河南·中原诗词文旅研学路线”5日研学路线；
3. 研学路线详情：每日节点、活动、餐饮与配套研学手册；
4. 研学路线PDF中的路线/日程配图已压缩放入 assets/study/，可继续接入页面；
5. 诗词搜索与诗词详情页。

运行：
1. 解压本压缩包；
2. 打开微信开发者工具；
3. 选择“导入项目”，选择解压后的文件夹；
4. AppID 没有正式小程序 AppID 时，可先使用测试号/游客模式；
5. 编译即可看到诗词和研学路线。

说明：
- 目前诗词和研学路线均为本地静态数据，适合课程/项目 Demo。
- 后续可以继续加入景点 Word、景点图片、朗诵音频、地图坐标、二维码和3D数字沙盘。
- 研学路线内容依据用户提供的《研学路线高清版.pdf》页面整理；该PDF为图片型文档，文字并非原生可复制文本。


### 地图黑块修复说明
地图页已改为本地绘制的中原诗词文化示意地图，不再依赖微信原生地图瓦片加载，因此不会再出现原生地图加载异常导致的黑色块。地图为示意图，不提供实时定位/导航；下方文化点位列表仍可点击查看详情。
