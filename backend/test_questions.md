# 中原诗旅智导 · 后端测试问题清单（>=10 条）

> 用途：验证 POST /api/poetry/ask 回答质量，覆盖诗词知识、景点关联、研学建议、
> 模糊问题、超出知识范围等问题类型。运行方式见 test_api.ps1 与 README.md。

## 一、诗词知识类
1. 《静夜思》的作者是谁？“床前明月光”中的“床”一般指什么？
2. 《春晓》的作者是谁？这首诗表达了什么？
3. “洛阳亲友如相问”的下一句是什么？作者是谁？
4. 《春望》中“感时花溅泪”表达了作者怎样的情感？
5. 李白和杜甫合称什么？两人的诗歌风格有何不同？

## 二、诗人与中原关联类
6. 杜甫为什么被称为“诗圣”？他和河南有什么关系？
7. 李商隐是哪里人？《锦瑟》表达了怎样的情感？

## 三、景点 / 线路关联类
8. 《诗经·卫风·淇奥》和河南哪个地方有关？
9. 龙门石窟和诗词文化有什么关系？
10. 请推荐一条适合亲子研学的洛阳诗词一日游路线。

## 四、研学建议 / 开放问题类
11. 学习古诗词对小学生有什么好处？
12. 背诵三句带“月”的唐诗并说明出处。
13. 《早发白帝城》表达了诗人怎样的心情？

## 五、边界 / 超出范围类
14. 1+1 等于几？（验证非诗词问题也不乱编）
15. 《不存在的诗集·无名篇》的作者是谁？（验证资料不足时如实说明不确定）

## 六、异常输入类（不走模型）
16. 空字符串问题。
17. 缺少 question 字段。
18. 无效 JSON 请求体。
